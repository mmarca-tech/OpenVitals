# OpenVitals 2.6.1

Released 2026-08-06.

This release puts a navigator next to the recorder. With a CoMaps build that shares its navigation, a GPS recording shows the guidance you are actually following - the turn, the route, the destination - while OpenVitals keeps doing the one thing it was doing: recording. CoMaps plans and navigates; OpenVitals reads and records. Nothing read from CoMaps is written to Health Connect.

### Added

- **Live CoMaps navigation while recording.** With the integration on and a CoMaps build that shares navigation:
  - The next turn floats over the live recording map - direction, distance, and the street it turns onto - and the stats dashboard offers a guidance tile the layout editor can place like any other.
  - The planned route is drawn point-for-point on the offline map, the same geometry CoMaps draws: a wide cased blue line with white bent arrows through every turn and a flag on the destination. The location dot becomes a compass arrow that points where the phone points.
  - Start becomes a doorway: with guidance enabled, the setup screen's Start opens the armed recording view, where you set the route up in CoMaps or dismiss the guidance card - then Start begins the session. Already guiding, dismissed, or integration off: Start starts immediately.
  - Guidance shown during the ride can be kept with the saved activity and read back on its detail screen - on this device only, never in Health Connect. Deleting the activity deletes it.
  - Observed, not polled: CoMaps announces each change and OpenVitals listens; a phone that is navigating nowhere is never queried. Off by default under Settings > Activity recording, guarded by CoMaps' own runtime permission.
- **One launcher icon.** The release build ships the artwork the debug build had; debug keeps the shape and differs only in colour.

### Fixed

- **3-button system navigation no longer covers the bottom of screens.** Screens without the app's own navigation bar now leave room for the system bar.
- **Heart and vitals tiles open their own metric screens.** Tapping Blood pressure opens the blood pressure detail directly; the intermediate Heart & Vitals overview is gone.
- **The swipe-to-delete red stays hidden until the row is swiped.** It used to show through entry rows at rest.
- **One reload shows one indicator.** The pull spinner answers the pull gesture; background syncs speak through the inline banner - never both. Dashboard widgets replay their animations only when a reload actually brought new data.

The app keeps the same package name and signing certificate, so this installs as a normal update.

Distribution flow:

- Codeberg release with signed APK, signed debug APK, and signed Android App Bundle assets.
- Direct Google Play production upload from the approved Woodpecker deployment.
